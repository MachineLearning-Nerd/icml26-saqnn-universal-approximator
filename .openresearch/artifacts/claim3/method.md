# Claim 3 method

The audit evaluates logarithmic formulas to avoid overflow. It checks 36
fixed-dimension/high-accuracy slope cells and 27
fixed-accuracy/high-dimension size cells. Independent unit tests assert the
regime conditions. A fixed-dimension, very-high-accuracy control must reverse
the circuit-size comparison, and the loose uniform sufficient-`n` display
must not masquerade as the tight `d/s` rate.
